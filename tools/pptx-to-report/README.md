# Свод недели SIGIR из pptx

Перетащил собранную `.pptx` (слайды по отделам, как для еженедельного собрания) —
получил рядом один `.html`-отчёт в утверждённой ledger-дизайн-системе SIGIR
(фиолетово-оранжевый бренд, Montserrat+Golos Text, без карточек) — тот же стиль,
что и у живого еженедельного свода. Без участия Claude — чистый детерминированный
разбор pptx.

## Использование (готовый .exe)

1. Открыть `dist\SIGIR-свод-из-pptx.exe`.
2. Перетащить `.pptx` в окно (или кнопка «...или выбрать файл»).
3. Рядом появится `<имя>_свод.html`, откроется в браузере автоматически.

Номер недели берётся из имени файла (последнее число в названии, например
«...собрание 34.pptx» → неделя 34), дата/период собрания — с титульного слайда
(`DD месяц YYYY г`).

## Честно о качестве автосборки

Часть слайдов в этой деке — «стандартные»: два столбца, подписи-разделы
(«Ключевые события прошлой недели:», «Ключевые планы новой недели:», «Метрики,
достижения, показатели:», «Риски, просьбы:», «Отпуск, отсутствия в отделе:»).
Эти разбираются надёжно — геометрия для них проверена на нескольких неделях.

Слайды с произвольной сеткой (Продажи, Подрядчики, HR, IT/IS и подобные —
у каждого свой рукописный макет) разбираются эвристикой по коротким
подписям-ярлыкам (всё, что похоже на «Слово:» — становится заголовком блока,
всё, что физически попадает под него по вертикали — его содержимым). Данные
не теряются (весь текст/таблицы/графики попадают в отчёт), но группировка
может быть менее аккуратной, чем у отдела с чистым 2-колоночным макетом —
иногда разные подписи этого же блока окажутся в одном месте без явного
разделения. Это компромисс детерминированного инструмента без LLM в цикле.

Если на реальных декабрьских/будущих деках вылезут систематические проблемы —
разбирать и чинить эвристику в `convert.py` (функция `build_department`),
список регулярных выражений для футера (`FOOTER_TRIPLE_RE`, `FOOTER_BLOCK_HINTS`)
и правило `is_label` для определения подписи-ярлыка.

## Сборка .exe заново

```
pip install python-pptx pillow pyinstaller tkinterdnd2
powershell -File build.ps1
```

Результат: `dist\SIGIR-свод-из-pptx.exe` (однофайловый).

## CLI (для отладки без GUI)

```
python convert.py вход.pptx выход.html [--week 34]
```
