# Выравнивание слайдов SIGIR

Берёт .pptx, собранный из присланных отделами слайдов, и чинит геометрию каждого
слайда: растягивает контент на всю полезную площадь страницы (без больших пустых
полей по бокам) и подбирает максимальный читаемый шрифт, который ещё влезает в блок.
Дизайн/цвета/шрифты самих блоков не трогает — только размер и положение.

Не трогает верхнюю полосу с названием отдела (title) — считает её шапкой и не
растягивает.

## Использование (готовый .exe)

1. Открыть `dist\SIGIR-выравнивание-слайдов.exe` (после сборки — см. ниже).
2. Перетащить .pptx в окно (или кнопка «...или выбрать файл»).
3. Рядом с исходным файлом появится `<имя>_выровнено.pptx`.

Можно скормить несколько .pptx подряд — каждый обрабатывается независимо.

## Сборка .exe заново

Нужны Python 3.12+, `pip install python-pptx pillow pyinstaller tkinterdnd2`.

```
powershell -File build.ps1
```

Результат: `dist\SIGIR-выравнивание-слайдов.exe` (однофайловый, ничего
дополнительно устанавливать на целевой машине не нужно). Шаблон
`референс общей презентации.pptx` вшивается в exe при сборке — если меняется
шаблон, нужно положить новый файл с этим же именем в папку и пересобрать.

## Как это работает (layout_fix.py)

Для каждого слайда:
1. Шапка (верхняя ~9% высоты слайда) не трогается.
2. Для остального контента считается общий bounding box всех фигур и сравнивается
   с целевой областью (почти вся страница под шапкой, с небольшими полями).
3. Если контент не заполняет область — все фигуры растягиваются (одинаковый
   масштаб по X и по Y) так, чтобы bounding box совпал с целевой областью,
   *сохраняя их взаимное расположение* (колонки остаются колонками).
4. Для таблиц дополнительно пропорционально растягиваются колонки/строки.
5. Для текстовых блоков после изменения размера подбирается наибольший кегль
   (9–32pt), который ещё помещается в получившийся блок — методом измерения
   текста через Pillow (шрифт Calibri/Arial, приближённо).

Это эвристика, не точный рендер PowerPoint — возможны небольшие огрехи
(чуть мельче/крупнее, чем идеально). Если на тестовых декабрьских/прошломесячных
жеках вылезут систематические косяки — их стоит разобрать и подправить константы
в начале `layout_fix.py` (TITLE_BAND_FRACTION, MAX_FONT_PT, LINE_HEIGHT_FACTOR и т.д.)
или прислать для доработки.

## CLI (для отладки без GUI)

```
python layout_fix.py вход.pptx выход.pptx [шаблон.pptx]
```
